5. Add a context menu to copy, copy as Markdown, copy link, open and add to note

9. Commit notes between turns and guard the notes folder from the agent's edits
10. Keep a discarded job's notes and commit notes taken outside a job
11. Add the Notes pane, the project's Notes, the editor and Add to note
12. Search notes globally and mention them with @
13. Turn a note into an idea that carries its media
14. Start a job from an idea that asks its questions first
15. Document notes, ideas and visual evidence in the guide and the architecture
16. Publish an idea as a forge issue
17. Show a documentation companion's permission request in its job's conversation and require an answer
