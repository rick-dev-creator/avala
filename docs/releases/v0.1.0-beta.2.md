**Agents you can trust without watching.**

The second beta of Avala, for Windows and Linux. It is a **prerelease**: expect rough edges, and please report them. Installed with the Windows installer, the portable zip or the AppImage, 0.1.0-beta.1 offers this update in place.

## What changed since 0.1.0-beta.1

**The simulator is no longer in the packages.** The simulated harness, the simulated forge and the session recorder exist only to develop and test Avala. 0.1.0-beta.1 included them and offered a simulator connection in developer mode, with `AVALA_DEVELOPER=1`; from this build on, no installer, archive, AUR package or Flatpak holds them, and `AVALA_DEVELOPER` does nothing in a package. A build from source still has them for development; see [Contributing](https://github.com/rick-dev-creator/avala/blob/main/CONTRIBUTING.md).

**Claude Code is the supported harness.** It is the only harness Avala officially supports. The welcome tour, the welcome screen and the connection editor in Settings offer Claude Code alone: with Claude Code missing or signed out, the tour shows the command that installs it and the one that signs in.

**Usage and Resources read better.** The Usage page gives each job's cost a column wide enough for it, and both pages say "held once" and "1 process" in the singular.

Everything else is as described in the [0.1.0-beta.1 notes](https://github.com/rick-dev-creator/avala/releases/tag/v0.1.0-beta.1).

## Supported harness

- **Claude Code.** Avala runs the `claude` CLI in its streaming JSON mode, so Claude Code must be installed, with `claude` on the `PATH`, and signed in. Avala finds each login on its own: the default `~/.claude` folder, other `~/.claude-*` folders, the folder in `CLAUDE_CONFIG_DIR`, or an API key or token in the environment, and offers a connection for each.

## Downloads

| Platform | Download | What it is |
| --- | --- | --- |
| Windows x64 | `avala-0.1.0-beta.2-win-x64-setup.exe` | the installer: Avala in `%LocalAppData%\Avala.Desktop`, with Start menu and desktop shortcuts, updating itself |
| Windows x64 | `avala-0.1.0-beta.2-win-x64-portable.zip` | the same, unzipped anywhere, updating itself |
| Linux x64 | `avala-0.1.0-beta.2-linux-x64.AppImage` | one file to make executable and run, updating itself |
| Linux x64 | `avala-0.1.0-beta.2-linux-x64.tar.gz` | `avala-0.1.0-beta.2/` with `Avala`, `avala.png` and `avala.desktop`, for package managers and by hand |
| Arch Linux | `avala-bin-0.1.0-beta.2.PKGBUILD` | the recipe of the AUR package `avala-bin`, built from the tar.gz |

Each package is self-contained, and every installer and archive has a `.sha256` checksum next to it. The builds are still unsigned: Windows SmartScreen warns about an unknown publisher, and Linux packages are checked against their `.sha256`.

## Check a package before trusting it

`./Avala --version` prints `Avala 0.1.0-beta.2 (<commit>)`, and `./Avala --smoke` starts the real application headless in a temporary data folder and prints `Avala <version> composed <n> pages and showed its main window.` On Windows, pipe them to `Out-Host` in PowerShell.

## Privacy

Unchanged from 0.1.0-beta.1: anonymous usage statistics to [Aptabase](https://aptabase.com), on by default, an `installed` event once and an `active` event at most once per local day, and nothing about your repositories, jobs, prompts, paths, harnesses, connections, accounts, costs or features. Turn it off on the first-run notice, in Settings, About, or with `DO_NOT_TRACK=1` or `AVALA_TELEMETRY=0`.

## Known limitations

- This is a beta prerelease, told about later prereleases as well as stable releases.
- Windows and Linux only for now; macOS packages come later.
- Packages are unsigned.
- Claude Code is the only supported harness.
- No Flatpak on Flathub yet; the Flatpak can be built from the tar.gz.

## Reporting issues
