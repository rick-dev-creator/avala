**Agents you can trust without watching.**

The fourth beta of Avala, for Windows and Linux. It is a **prerelease**: expect rough edges, and please report them. Installed with the Windows installer, the portable zip or the AppImage, an earlier beta offers this update in place.

## What changed since 0.1.0-beta.3

This release shows what matters in the conversation, organizes it, and spends your usage more carefully.

**What is left, at a glance.** The job's header shows two small rings beside the status:
- **Context left**: how much of the model's context window the conversation still has, and when Claude Code compacted it ([#9](https://github.com/rick-dev-creator/avala/issues/9)).
- **Usage left**: what is left of the connection's most used usage window, which turns amber near its limit and opens the Usage page on that connection ([#10](https://github.com/rick-dev-creator/avala/issues/10)).

**Projects in the sidebar** ([#8](https://github.com/rick-dev-creator/avala/issues/8)).
- Needs you stays on top, then one project per repository, then **Chats** for jobs started without one.
- Each project folds its done jobs under "N done", and folds are remembered.
- **+** makes a project; Rename and Delete Project are in its menu.
- **Move to** on a row moves a conversation to another project, or to a new one.

**Archive conversations** ([#7](https://github.com/rick-dev-creator/avala/issues/7)).
- Point at a row that is ready for review or finished and click its archive glyph, press Ctrl/⌘+Shift+A, or choose Archive in its menu. **Archive Done** archives every finished conversation of a project.
- **Archived** at the foot of the sidebar opens the Archived page, where a conversation is restored or opened.
- Archiving never touches the job, its transcript, records, usage or worktree.
- A conversation that is working or needs you is never archived, and an archived one that works again comes back by itself.

**Your usage window is spent more carefully.** An audit compared a job in Avala with Claude Code in a terminal. One message costs the same in both. But Avala let a conversation grow to over half a million tokens, and resumed held jobs by itself the moment a usage window reset, while nobody was there.
- **Claude Code compacts a long conversation sooner** ([#68](https://github.com/rick-dev-creator/avala/issues/68)). Started the way Avala starts it, Claude Code compacted only at 967,000 tokens. Avala now starts every session with a 250,000-token window, so a conversation is summarized at about 217,000 tokens, and each message, and each message after an idle hour, reads far less.
- **A section of its own in Settings.** Under **Claude Code**, each login has Compact at 150k, 250k, 500k or 1M, and switches for Summarize automatically and Summarize while idle. A change is saved at once, and the same settings can be written in `connections.json` as `compactAt`, `autoCompact` and `idleCompaction`.
- **A held job waits for you after a reset** ([#69](https://github.com/rick-dev-creator/avala/issues/69)). A job held near its usage limit no longer resumes the moment its window resets. Its row says "window reset · waiting for you", and your next message resumes it. To have it resume by itself as before, set `"resumeAtReset": "auto"` in the `limits` section of `.avala/jobs.json` or in `limits.json`.

**A stuck stop no longer blocks a job.** An agent that never confirms Stop within 30 seconds has its session stopped instead, the log says so, and your next message continues the job ([#18](https://github.com/rick-dev-creator/avala/issues/18)).

**Avala's icon on the desktop** ([#30](https://github.com/rick-dev-creator/avala/issues/30)). On Linux the running window now names itself after its desktop entry, on Wayland and on X11, so panels, docks and window switchers show its icon. The tar.gz and the AUR package install the icon in every size, from 16 to 512 pixels and scalable.

**Behind the scenes.** Avalonia moves to 12.1.4. Tests that failed at random on Windows (#65) and macOS (#75) were fixed at their cause, so CI is reliable again.

Everything else is as described in the [0.1.0-beta.3 notes](https://github.com/rick-dev-creator/avala/releases/tag/v0.1.0-beta.3).

## Supported harness

- **Claude Code.** Avala runs the `claude` CLI in its streaming JSON mode, so Claude Code must be installed, with `claude` on the `PATH`, and signed in. Avala finds each login on its own: the default `~/.claude` folder, other `~/.claude-*` folders, the folder in `CLAUDE_CONFIG_DIR`, or an API key or token in the environment, and offers a connection for each.

Each package is self-contained, and every installer and archive has a `.sha256` checksum next to it. The builds are still unsigned: Windows SmartScreen warns about an unknown publisher, and Linux packages are checked against their `.sha256`.

## Check a package before trusting it

`./Avala --version` prints `Avala 0.1.0-beta.4 (<commit>)`, and `./Avala --smoke` starts the real application headless in a temporary data folder and prints `Avala <version> composed <n> pages and showed its main window.` On Windows, pipe them to `Out-Host` in PowerShell.

## Privacy

Unchanged from 0.1.0-beta.1: anonymous usage statistics to [Aptabase](https://aptabase.com), on by default, an `installed` event once and an `active` event at most once per local day, and nothing about your repositories, jobs, prompts, paths, harnesses, connections, accounts, costs or features. Turn it off on the first-run notice, in Settings, About, or with `DO_NOT_TRACK=1` or `AVALA_TELEMETRY=0`.

## Known limitations

- This is a beta prerelease, told about later prereleases as well as stable releases.
- Windows and Linux only for now; macOS packages come later.
- Packages are unsigned.
- Claude Code is the only supported harness.
- No Flatpak on Flathub yet; the Flatpak can be built from the tar.gz.
- The Archived page has no search yet, and nothing is archived automatically.
