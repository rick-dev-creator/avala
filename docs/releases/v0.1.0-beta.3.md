**Agents you can trust without watching.**

The third beta of Avala, for Windows and Linux. It is a **prerelease**: expect rough edges, and please report them. Installed with the Windows installer, the portable zip or the AppImage, an earlier beta offers this update in place.

## What changed since 0.1.0-beta.2

This release makes long-running conversations reliable ([#16](https://github.com/rick-dev-creator/avala/issues/16)).

**A turn ends when the agent finishes.** When you sent a message while the agent was working, Claude Code took it into the work underway and answered both at once, but Avala waited for a separate answer to each message. It never saw the turn end: Thinking… stayed on after every reply ([#11](https://github.com/rick-dev-creator/avala/issues/11)), and the job looked busy forever. Avala now follows what Claude Code reports about each message it was sent, and ends the turn when none is left waiting.

**A message is never lost.** A job that looked busy and fell silent for fifteen minutes was held as stalled, and that hold could wait forever for an agent that had nothing left to stop, so the next message you sent did nothing ([#15](https://github.com/rick-dev-creator/avala/issues/15)). Now:

- a conversation left alone between turns is never held as stalled;
- stopping an agent that is idle completes at once;
- a held job says why in its composer, such as "Held · stalled · send a message to continue the job…", and a message sent to it continues the job;
- every hold, and every message Avala refuses, is written to the log with its reason.

Everything else is as described in the [0.1.0-beta.2 notes](https://github.com/rick-dev-creator/avala/releases/tag/v0.1.0-beta.2).

## Supported harness

- **Claude Code.** Avala runs the `claude` CLI in its streaming JSON mode, so Claude Code must be installed, with `claude` on the `PATH`, and signed in. Avala finds each login on its own: the default `~/.claude` folder, other `~/.claude-*` folders, the folder in `CLAUDE_CONFIG_DIR`, or an API key or token in the environment, and offers a connection for each.

## Downloads

| Platform | Download | What it is |
| --- | --- | --- |
| Windows x64 | `avala-0.1.0-beta.3-win-x64-setup.exe` | the installer: Avala in `%LocalAppData%\Avala.Desktop`, with Start menu and desktop shortcuts, updating itself |
| Windows x64 | `avala-0.1.0-beta.3-win-x64-portable.zip` | the same, unzipped anywhere, updating itself |
| Linux x64 | `avala-0.1.0-beta.3-linux-x64.AppImage` | one file to make executable and run, updating itself |
| Linux x64 | `avala-0.1.0-beta.3-linux-x64.tar.gz` | `avala-0.1.0-beta.3/` with `Avala`, `avala.png` and `avala.desktop`, for package managers and by hand |
| Arch Linux | `avala-bin-0.1.0-beta.3.PKGBUILD` | the recipe of the AUR package `avala-bin`, built from the tar.gz |

Each package is self-contained, and every installer and archive has a `.sha256` checksum next to it. The builds are still unsigned: Windows SmartScreen warns about an unknown publisher, and Linux packages are checked against their `.sha256`.

## Check a package before trusting it

`./Avala --version` prints `Avala 0.1.0-beta.3 (<commit>)`, and `./Avala --smoke` starts the real application headless in a temporary data folder and prints `Avala <version> composed <n> pages and showed its main window.` On Windows, pipe them to `Out-Host` in PowerShell.

## Privacy

Unchanged from 0.1.0-beta.1: anonymous usage statistics to [Aptabase](https://aptabase.com), on by default, an `installed` event once and an `active` event at most once per local day, and nothing about your repositories, jobs, prompts, paths, harnesses, connections, accounts, costs or features. Turn it off on the first-run notice, in Settings, About, or with `DO_NOT_TRACK=1` or `AVALA_TELEMETRY=0`.

## Known limitations

- This is a beta prerelease, told about later prereleases as well as stable releases.
- Windows and Linux only for now; macOS packages come later.
- Packages are unsigned.
- Claude Code is the only supported harness.
- No Flatpak on Flathub yet; the Flatpak can be built from the tar.gz.
