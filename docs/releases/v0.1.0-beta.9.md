**Know when CI fails, read long output, and tune each kind of sub-agent.**

The ninth beta of Avala, for Windows and Linux. It is a **prerelease**: expect rough edges, and please report them. Installed with the Windows installer, the portable zip or the AppImage, an earlier beta offers this update in place.

## What changed since 0.1.0-beta.8

**CI in the conversation** ([#108](https://github.com/rick-dev-creator/avala/issues/108)). While the checks of a job's pull request run, the job's header shows "Checks running · 1 of 3", each check in its tooltip. Once every check of a commit has ended, the conversation says how: a card "CI failed: build" names the failing checks with their summaries and a **Log** link to each, and **Ask the agent to fix it** sends the agent those checks when the job takes a message. When the repository wakes the agent on failing CI, the card says it was woken instead. When every check passed, one quiet line says so. Each commit gets one card, also on a pull request the agent opened itself.

**Long output, folded** ([#109](https://github.com/rick-dev-creator/avala/issues/109)). A command's output longer than 20 lines opens on its last 20, with **Show N earlier lines** above them. When the command failed, the lines that name an error, a failed test or a failed build, up to eight, are listed above the output, so the cause is visible without scrolling through the log.

**Settings per kind of sub-agent** ([#110](https://github.com/rick-dev-creator/avala/issues/110)). The `delegation` section of `.avala/jobs.json` takes a `roles` object that gives `worker`, `reviewer` and `research` children their own `model`, `effort` and `compactAt`, used when the parent's call leaves them out. A research child can run a cheaper model and compact sooner, for example `{ "roles": { "research": { "model": "haiku", "effort": "low", "compactAt": 120000 } } }`. The Delegation pane's footer names every window a connection's jobs compact at, such as "compacts at 120k or 250k".

Everything else is as described in the [0.1.0-beta.8 notes](https://github.com/rick-dev-creator/avala/releases/tag/v0.1.0-beta.8).

## Supported harness

- **Claude Code.** Avala runs the `claude` CLI in its streaming JSON mode, so Claude Code must be installed, with `claude` on the `PATH`, and signed in. Avala finds each login on its own: the default `~/.claude` folder, other `~/.claude-*` folders, the folder in `CLAUDE_CONFIG_DIR`, or an API key or token in the environment, and offers a connection for each.

## Check a package before trusting it

`./Avala --version` prints `Avala 0.1.0-beta.9 (<commit>)`, and `./Avala --smoke` starts the real application headless in a temporary data folder and prints `Avala <version> composed <n> pages and showed its main window.` On Windows, pipe them to `Out-Host` in PowerShell.

## Privacy

Unchanged from 0.1.0-beta.1: anonymous usage statistics to [Aptabase](https://aptabase.com), on by default, an `installed` event once and an `active` event at most once per local day, and nothing about your repositories, jobs, prompts, paths, harnesses, connections, accounts, costs or features. Turn it off on the first-run notice, in Settings, About, or with `DO_NOT_TRACK=1` or `AVALA_TELEMETRY=0`. Attachments and drafts stay on your machine; attachments go only to the harness of the job they were sent with.

## Known limitations

- This is a beta prerelease, told about later prereleases as well as stable releases.
- Windows and Linux only for now; macOS packages come later.
- Packages are unsigned.
- Claude Code is the only supported harness.
- No Flatpak on Flathub yet; the Flatpak can be built from the tar.gz.
- The Archived page has no search yet, and nothing is archived automatically.
- A peek shows text files only; images and pages open in their own preview.
- Continue on your phone needs a harness that offers it: today Claude Code signed in with claude.ai. A sub-agent shows what it does and its state, not its type.
- The welcome screen's composer does not take attachments yet; attach them once the job has started.
- Whether Claude Code's own sub-agents compact at their connection's window has not been confirmed yet.
