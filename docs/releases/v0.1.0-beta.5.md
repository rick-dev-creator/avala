**Agents you can trust without watching.**

The fifth beta of Avala, for Windows and Linux. It is a **prerelease**: expect rough edges, and please report them. Installed with the Windows installer, the portable zip or the AppImage, an earlier beta offers this update in place.

## What changed since 0.1.0-beta.4

This release makes the conversation read like the editor you use all day, and says what a message will cost before you send it.

**Code in VS Code's colors** ([#80](https://github.com/rick-dev-creator/avala/issues/80)). Code blocks take the colors of VS Code's Dark+ and Light+ themes, now at any length: long blocks are no longer left plain, and a block of 30 lines or more numbers its lines.

**Actions on code blocks** ([#84](https://github.com/rick-dev-creator/avala/issues/84)). A block says its language and length, and on hover offers Wrap lines, Save as… and Open in the editor.

**Each edit as its diff** ([#81](https://github.com/rick-dev-creator/avala/issues/81)). A file edit's line expands into the lines that edit removed and added, so a wrong turn shows while the agent still works. Every change to the file is one click away.

**Richer replies** ([#83](https://github.com/rick-dev-creator/avala/issues/83)). GitHub callouts (`> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`), footnotes and typeset math (`$…$` and `$$…$$`). A wide table scrolls sideways instead of squeezing its columns.

**Files, commits and issues are links** ([#82](https://github.com/rick-dev-creator/avala/issues/82)). A path the agent mentions, such as `src/Invoice.cs:42`, opens a peek of the file from the job's worktree at that line. A commit hash and `#123` open on the repository's GitHub, Gitea or Forgejo page.

**Your usage window is your login's** ([#71](https://github.com/rick-dev-creator/avala/issues/71)). The usage ring and the Usage page say the window is shared with every app signed in to that login, Claude Code in a terminal included, and a window that rose while Avala was idle says so.

**A message to a cold conversation** ([#70](https://github.com/rick-dev-creator/avala/issues/70)). Claude Code keeps a conversation's prompt cache for an hour. After that, the next message re-reads the whole conversation. When a large conversation has been idle that long, the composer says how many tokens your message will re-read and offers **Compact first**.

**Behind the scenes.** Two tests that failed at random on Windows and macOS were fixed at their cause. Math is drawn with CSharpMath, a new dependency.

Everything else is as described in the [0.1.0-beta.4 notes](https://github.com/rick-dev-creator/avala/releases/tag/v0.1.0-beta.4).

## Supported harness

- **Claude Code.** Avala runs the `claude` CLI in its streaming JSON mode, so Claude Code must be installed, with `claude` on the `PATH`, and signed in. Avala finds each login on its own: the default `~/.claude` folder, other `~/.claude-*` folders, the folder in `CLAUDE_CONFIG_DIR`, or an API key or token in the environment, and offers a connection for each.

| Platform | Download | What it is |
| --- | --- | --- |
| Windows x64 | `avala-0.1.0-beta.5-win-x64-setup.exe` | the installer: Avala in `%LocalAppData%\Avala.Desktop`, with Start menu and desktop shortcuts, updating itself |
| Windows x64 | `avala-0.1.0-beta.5-win-x64-portable.zip` | the same, unzipped anywhere, updating itself |
| Linux x64 | `avala-0.1.0-beta.5-linux-x64.AppImage` | one file to make executable and run, updating itself |
| Linux x64 | `avala-0.1.0-beta.5-linux-x64.tar.gz` | `avala-0.1.0-beta.5/` with `Avala`, `avala.desktop`, `avala.png` and `icons/hicolor/` in every size, for package managers and by hand |
| Arch Linux | `avala-bin-0.1.0-beta.5.PKGBUILD` | the recipe of the AUR package `avala-bin`, built from the tar.gz |

Each package is self-contained, and every installer and archive has a `.sha256` checksum next to it. The builds are still unsigned: Windows SmartScreen warns about an unknown publisher, and Linux packages are checked against their `.sha256`.

## Check a package before trusting it

`./Avala --version` prints `Avala 0.1.0-beta.5 (<commit>)`, and `./Avala --smoke` starts the real application headless in a temporary data folder and prints `Avala <version> composed <n> pages and showed its main window.` On Windows, pipe them to `Out-Host` in PowerShell.

## Privacy

Unchanged from 0.1.0-beta.1: anonymous usage statistics to [Aptabase](https://aptabase.com), on by default, an `installed` event once and an `active` event at most once per local day, and nothing about your repositories, jobs, prompts, paths, harnesses, connections, accounts, costs or features. Turn it off on the first-run notice, in Settings, About, or with `DO_NOT_TRACK=1` or `AVALA_TELEMETRY=0`.

## Known limitations

- This is a beta prerelease, told about later prereleases as well as stable releases.
- Windows and Linux only for now; macOS packages come later.
- Packages are unsigned.
- Claude Code is the only supported harness.
- No Flatpak on Flathub yet; the Flatpak can be built from the tar.gz.
- The Archived page has no search yet, and nothing is archived automatically.
- A peek shows text files only; images and pages open in their own preview.
