# Guide

How to use Avala, one feature per page. Read Getting started first; the rest can be read in any order, though this order follows a job from its start to its review and beyond. Every page has the same sections, described in [how a guide page is written](../README.md#how-a-guide-page-is-written).

## Start

1. [Getting started](getting-started.md): install, the welcome tour, connecting agents and accounts.
2. [Jobs and conversations](jobs-and-conversations.md): starting a job, the composer, the harness chip, copying and exporting.
3. [Repositories](repositories.md): opening, cloning, creating and publishing repositories, and scratch repositories.

## Trust

4. [Permissions and autonomy](permissions-and-autonomy.md): answering requests, autonomy, and `.avala/permissions.json`.
5. [Checks and review](checks-and-review.md): `.avala/checks.json`, the verdict, and approving, sending back or discarding.
6. [Budgets and usage limits](budgets-and-usage-limits.md): caps, the daily ceiling, holds and handoffs.

## Scale

7. [Delegation and orchestration](delegation-and-orchestration.md): sub-agents as child jobs.
8. [Best of N](best-of-n.md): several candidates, the best kept by its evidence.
9. [Autopilot and triggers](autopilot-and-triggers.md): schedules, webhooks, forge events and loops.
10. [Pull requests and CI](pull-requests-and-ci.md): opening pull requests and waking the agent on failures.
11. [Feature documentation](feature-documentation.md): versions with a C4 diagram, change requests, the C4 player and the docs site.

## Everyday

12. [Canvas and previews](canvas-and-previews.md): SVG, Markdown and Mermaid canvases, and the web preview.
13. [Notifications](notifications.md): your phone, through ntfy or a webhook.
14. [Privacy and usage statistics](privacy-and-usage-statistics.md): what is sent, and hiding personal details.
15. [Keyboard shortcuts](keyboard-shortcuts.md).
16. [Troubleshooting](troubleshooting.md): could not start, logs, Wayland and web views.
